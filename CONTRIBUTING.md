# Contributing

1. Never use real X content, credentials or cookies in issues, fixtures, screenshots or commits.
2. Keep identifiers, API fields and machine-readable errors in English. Write only useful, non-obvious inline comments, in Turkish.
3. Add tests for security boundaries, parsing changes and SQL/query behavior.
4. Run backend and frontend checks documented in `README.md`.
5. Do not add scraping, browser automation, rate-limit bypass, account rotation or X-content model training.
6. Update `CHANGELOG.md` for user-visible changes.

## Türkçe

Gerçek X içeriğini veya sırları issue, fixture, ekran görüntüsü ve commitlerde kullanmayın. Kod sembolleri/API alanları İngilizce; gerekli açıklayıcı yorumlar Türkçe olmalıdır. Scraping, browser automation, rate-limit atlatma veya X içeriğiyle model eğitimi ekleyen katkılar kabul edilmez.
