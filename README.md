## 📖 What Is This?

Timeline-cti-explorer is a free tool that watches Twitter (now called X) for posts about cyber threats. It collects **Indicators of Compromise (IOCs)** and **Posts of Compromise (POCs)** automatically. This means it finds suspicious links, bad IP addresses, malicious file hashes, and warning messages from security experts—all in one place.

Think of it as a smart security assistant that reads Twitter for you. It saves you hours of manual searching. Instead of scrolling through thousands of tweets, you get a clean list of threats people are talking about right now.

## 🔧 Troubleshooting

### The app won't start

1. Make sure you extracted the ZIP file completely.
2. Check that your antivirus didn't block the file. If it did, allow the app in your antivirus settings.
3. Try running the file as administrator (right-click → **Run as administrator**).

### No search results appear

1. Make sure you're connected to the internet.
2. Try a different search term. Broad terms like `virus` work better than specific ones.
3. Close and reopen the app.

### The app looks stretched or blurry

1. Right-click on the app icon.
2. Choose **Properties**.
3. Go to the **Compatibility** tab.
4. Click **Change high DPI settings**.
5. Check **Override high DPI scaling behavior** and choose **Application**.
