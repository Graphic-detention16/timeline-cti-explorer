# Benchmark results

No performance run has been completed on the documented reference server yet. The repository
therefore makes no verified 100-million-row or one-billion-row latency claim.

When the reference run is complete, preserve the raw k6 output, machine description, ClickHouse
settings, dataset seed and a Markdown summary in this directory. Never use estimated numbers.
